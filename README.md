# 🏠 ESP32 Bluetooth Home Automation System

---

## 📌 Project Overview

A **menu-driven home automation system** using ESP32 Bluetooth.
This project allows users to control multiple devices (LEDs as appliances) through a mobile phone using Bluetooth communication.

---

## 🚀 Features

✨ Individual LED Control (ON/OFF)
✨ LED Chasing (Forward & Backward)
✨ LED Blinking Mode
✨ Menu-Based User Interface
✨ Wireless Control via Bluetooth

---

## 🛠️ Components Used

* 🔹 ESP32 Development Board
* 🔹 LEDs (Red, Blue, Green, White)
* 🔹 220Ω Resistors
* 🔹 Breadboard & Jumper Wires

---

## 📱 Communication Method

* 📡 Bluetooth Classic (SPP - Serial Port Profile)
* 📲 Controlled via mobile app (*Serial Bluetooth Terminal*)

---

## 📋 Menu Options

| Option | Function                         |
| ------ | -------------------------------- |
| 1️⃣    | Individual LED Control           |
| 2️⃣    | LED Chasing (Forward & Backward) |
| 3️⃣    | All LEDs Blinking                |

---

## 🔌 Pin Configuration

| Device       | GPIO Pin |
| ------------ | -------- |
| 🔴 Red LED   | GPIO 14  |
| 🔵 Blue LED  | GPIO 27   |
| 🟢 Green LED | GPIO 13  |
| ⚪ White LED  | GPIO 12  |
